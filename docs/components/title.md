# Title

Heading text, H1 (32sp) through H6 (14sp), all bold by default. User styles override the
defaults.

```go
giode.H1("Welcome", giode.Styles{Color: giode.HexColor("#f8fafc")})
giode.H3("Section", giode.Styles{})
```

| Function | Size |
| --- | --- |
| `H1` | 32sp |
| `H2` | 28sp |
| `H3` | 24sp |
| `H4` | 20sp |
| `H5` | 16sp |
| `H6` | 14sp |
