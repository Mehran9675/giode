# Title

Bold headings in six sizes.

```go
giode.H1("Welcome", giode.Styles{Color: "theme.text"})
giode.H3("Recent files")
```

| Function | Size |
| --- | --- |
| `H1` | 32sp |
| `H2` | 28sp |
| `H3` | 24sp |
| `H4` | 20sp |
| `H5` | 16sp |
| `H6` | 14sp |

Styles work as for [Text](../elements.md#text) and override the defaults, including the
size and weight.
